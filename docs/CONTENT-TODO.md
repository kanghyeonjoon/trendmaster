# 게시 전 필수 교체 체크리스트

랜딩페이지(`docs/index.html`)는 구조·카피·디자인이 완성된 상태이지만,
아래 항목은 **자리표시자/예시값**이므로 실제 게시(광고 집행) 전에 반드시 교체해야 합니다.

> ⚠️ **가장 중요한 규칙**: 성과 숫자·후기는 절대 지어내면 안 됩니다.
> 허위·과장 표시는 표시광고법 위반이고, 신뢰가 한 번 무너지면 복구가 안 됩니다.
> 실측값이 생기기 전까지는 해당 섹션을 숨기는 게 차라리 낫습니다.

## 1. 설정 상수 (index.html 상단 `CONFIG`)

- [ ] `BRAND_NAME` — 브랜드명 확정 후 교체 (현재 "OO컴퍼니") → 페이지 전체 자동 반영
- [ ] `TALLY_URL` — 탈리폼 링크 입력 → 모든 CTA 버튼 연결 + 하단에 폼 자동 임베드
  - 탈리폼은 **입력칸 2개(병원명 + 연락처)** 로만 만들 것. 칸 하나가 늘 때마다 제출률이 떨어짐
  - 제출 완료 메시지에 "영업일 기준 24시간 내 연락드립니다" 명시 (콜백 약속)
- [ ] `COLUMN_LINKS` — 칼럼 3편 작성 후 링크 3개 입력
- [ ] `REVIEW_LINK` — 후기 모음(블로그/인스타) 링크 입력

## 2. 예시값 → 실측값 교체 (교체 후 `.sample-tag` 요소 삭제)

- [ ] **[6] 성공사례 3건** — 지역+진료과 이니셜, 기간, 성과 수치(%. 배수, 건수)
  - 고급: "문의 N건 × 전환율 %" 복합 지표가 가장 강력
- [ ] **[9] 카톡 캡처 4장** — 실제 대화 스크린샷 (개인정보 블러 + 핵심 문장 빨간 박스)
- [ ] **[9] 감성 후기 3줄** — 실제 고객 발언으로
- [ ] **[9] 장문 인터뷰 1건** — 실제 인터뷰로 (같은 처지 원장의 구체적 상황 묘사가 핵심)
- [ ] **[12-a] 원형 배지 2개** — 평균 계약유지 기간 / 최고 성과 실측값
- [ ] **[12-a] 인터뷰 영상 2개** — 유튜브 임베드 또는 썸네일+링크
- [ ] **[7] 비교표 우측** — 경력 연차 등 숫자 들어간 권위로 보강 (예: "14년차 전문가")

## 3. 푸터 사업자 정보 (신뢰 장치 — 반드시)

- [ ] 회사명(법인명) / 사업자등록번호 / 대표 실명 / 전화 / 주소
  - "숨지 않는 진짜 회사" 신호. 원본 페이지도 공동대표 실명까지 전부 공개함

## 4. 게시 전 최종 점검 (교재 6-3 체크리스트 요약)

- [ ] 모바일에서 첫 화면에 통증 카피 + 버튼 1개가 스크롤 없이 보이는가
- [ ] 모든 숫자·후기가 진짜인가 (예시값 잔존 여부 — `sample-tag` 검색해서 0개 확인)
- [ ] 의료광고 규제 표현 점검: "최고/1등/유일", "100%/완치/보장/부작용 없음" 없는지
  - 참고: "절대 성공 공식"은 원본도 쓴 표현이나, 광고 심의 대상 매체에 실을 경우 전문가 확인 권장
- [ ] 이미지(카톡 캡처 등) 용량 압축 + `loading="lazy"` 적용 (로딩 느리면 이탈)
- [ ] 폼 제출 후 콜백 프로세스 준비 — **5분 내 콜백**이 계약률을 가른다 (최소한 자동 안내 문자/카톡)

## 5. GitHub Pages 배포 방법

1. 이 브랜치의 PR을 main에 병합
2. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main`, Folder: `/docs` 선택 → Save
3. 1~2분 후 `https://<계정명>.github.io/trendmaster/` 에서 확인
